# Patches

OverPass Runtime is DXMT at the commit pinned in `dxmt/`, plus the patches in `patches/`.
`build.sh` applies them in order to the pinned checkout before building (a patch that is already applied is skipped).
New patches: change `dxmt/`, then `overpass/make-patch.sh "subject" "body"` writes the next numbered patch from it.
To start over from a clean DXMT, run `git -C dxmt checkout -- . && git -C dxmt clean -fd`.

Pinned: DXMT main at 9839e55 (2026-10-26). The patches were moved there from a148782 (2026-10-06), when DXMT
gained D3D12 geometry shaders, `SV_PrimitiveID`, `WriteBufferImmediate` and the minimum feature level. Where
both did the same job, DXMT's code was kept: mesh pipelines bind root arguments to the object and mesh stages
the way DXMT's geometry pipelines now do, and `GetAttributeAtVertex` goes through DXMT's input indexing
for geometry shaders (its vertex operand isn't a geometry shader vertex).

| Patch | What it does |
|---|---|
| `0001-nvapi-add-D3D12-DRS-D3D11-device-creation-and-GPU-di.patch` | Adds 36 NVAPI functions: D3D12 (shader extension and raytracing caps, Reflex queue calls, pipeline options), DRS sessions and profiles, `NvAPI_D3D11_CreateDevice(AndSwapChain)`, `NvAPI_D3D_RegisterDevice`, and GPU/display lookups (PCI IDs, GPU type and info, GPU IDs, logical/physical GPUs, display names). Behaviour adapted from dxvk-nvapi (MIT); the notice is kept in `src/nvapi/nvapi_ported.cpp`. |
| `0002-d3d11-report-DXGI-usage-from-bind-flags-and-CPU-acce.patch` | `IDXGIResource::GetUsage` reports what the resource can be used for (shader input, render target output, unordered access, CPU access) instead of 0. ANGLE checks it before rendering into a shared texture, so Chromium-based apps such as GOG Galaxy (Qt WebEngine) failed with "Unable to initialize SkSurface" and crashed. Verified: GOG Galaxy 2.1.10 shows its login window on DXMT. |
| `0003-d3d12-nvngx-DLSS-Super-Resolution-on-D3D12-through-M.patch` | DLSS Super Resolution for D3D12 games, served by MetalFX's temporal scaler: NGX's D3D12 entry points, and a command list extension (`IMTLD3D12CommandListExt`) that records the upscale into the game's command list. Motion vectors at output size are shrunk to render size by a compute pass first. Verified with `tests/dlss12.cpp` (both motion vector sizes): a single-colour frame upscales to an output of the same colour. |
| `0004-d3d12-tiled-resources-tier-2-through-Metal-placement.patch` | D3D12 tiled resources tier 2 and feature level 12_0. Reserved textures (2D, no MSAA) and buffers are Metal placement sparse resources with 64 KB pages, the size of D3D12 tiles; heaps can back their tiles. `UpdateTileMappings` and `CopyTileMappings` run on a Metal 4 queue, fenced against the D3D12 queue with an event. `GetResourceTiling` reports Metal's tile shapes (D3D12's standard shapes for 2D) and packed mip tail. Needs macOS 26.4 or later; on older systems the device stays at 11_1 without tiled resources. Verified with `tests/tiled12.cpp`: tile counts and shapes, data in mapped tiles, two resources aliased on one heap tile, copied mappings, reserved buffers, placed resources in the same heaps. |
| `0005-airconv-SM-6.6-resource-handles-createHandleFromBind.patch` | Shader model 6.6 resource handles: `createHandleFromBinding` and `annotateHandle` resolve to the same resource ranges as `createHandle`, so shaders compiled for 6.6 and later get as far as 6.0 ones. Measured with `tests/sm6/`: 6 → 7 of 27 features, and every 6.6+ shader now stops at its own feature instead of at handle creation. |
| `0006-airconv-DXIL-wave-and-quad-vote-operations.patch` | Wave operations map to Metal SIMD-group functions: sum, product, min, max, prefix ops, and/or/xor, ballot, read first lane, any/all/all-equal, bit counts, quad vote and `isHelperLane`. `WaveMatch`, `WaveMultiPrefix` and 64-bit reductions, which Metal lacks, combine the 32 lanes through shuffles. Measured with `tests/sm6/`: 7 → 14 of 27 features. |
| `0007-airconv-SM-6.1-6.8-small-ops-comparison-sampling-var.patch` | Small shader model 6.1 to 6.8 ops: `SampleCmpLevel`, `SampleCmpBias` and `SampleCmpGrad` (Metal `sample_compare`), `GatherRaw`, `dot4add`, `dot2add`, 8-bit pack and unpack, `SV_StartVertexLocation` and `SV_StartInstanceLocation`. `ViewID` is 0, since there is no view instancing. Measured with `tests/sm6/`: 14 → 20 of 27 features. |
| `0008-airconv-derivatives-outside-pixel-shaders-tan-comput.patch` | Derivatives in compute shaders (shader model 6.6), which Metal only has in fragment functions: outside pixel shaders a derivative is the difference with the neighbouring lane of the 2x2 quad. Coarse derivatives are computed as fine ones. Also fixes the DXIL `tan` op, which was translated to `sin`. Measured with `tests/sm6/`: 21 of 27 features. |
| `0009-airconv-d3d12-SM-6.6-descriptor-heap-indexing-Resour.patch` | Shader model 6.6 `ResourceDescriptorHeap` and `SamplerDescriptorHeap`. Root signatures with the directly-indexed heap flags get two more root arguments, the base addresses of the bound heaps, and the heap index becomes the register index of a synthetic range. Measured with `tests/sm6/`: 22 of 27 features. `tests/heap12.cpp` checks sampled and loaded values at runtime. |
| `0010-airconv-SV_Barycentrics-and-GetAttributeAtVertex.patch` | `SV_Barycentrics` maps to `[[barycentric_coord]]`. `GetAttributeAtVertex` on float inputs is solved in the pixel shader prologue from the interpolants and their screen derivatives, because Metal's per-vertex fragment input isn't usable on Apple9 GPUs (M3, M4). Integer and half inputs get the flat value for every vertex. Measured with `tests/sm6/`: 23 of 27 features. `tests/bary12.cpp` checks values at runtime. |
| `0011-airconv-d3d12-64-bit-atomics-on-buffers-and-groupsha.patch` | 64-bit atomics on buffers and groupshared memory. Unsigned min/max without a result map to Metal directly, add/and/or/xor are split into two 32-bit atomics, and the rest take a lock word from a 4096-word table per device (or 32 threadgroup words for groupshared memory). Also adds groupshared compare-exchange, D3D12 OPTIONS9/OPTIONS11 and `airconv -rootsig`. Measured with `tests/sm6/`: 24 of 27 features. `tests/atomic12.cpp` (1024 threads, split and locked paths) checks every result. Not done yet: atomics on `R64_UINT` typed textures. |
| `0012-airconv-d3d12-64-bit-atomic-min-max-without-Metal-s-.patch` | 64-bit atomic min/max on GPUs older than Apple8 (before M2), where Metal's native one is missing: the converter takes the lock word for them. OPTIONS11 now reports 64-bit atomics on descriptor heap resources, so heap buffers reach the same lock table. Verified: `tests/atomic12.cpp` gained a descriptor-heap variant, and the pre-Apple8 path was checked by forcing it on an M4. |
| `0013-airconv-d3d12-mesh-and-amplification-shaders.patch` | Mesh shaders become Metal mesh functions and amplification shaders Metal object functions. D3D12 gets mesh pipelines from pipeline state streams, `ID3D12GraphicsCommandList3` to `6`, `DispatchMesh` and render passes, and reports mesh shader tier 1. Measured with `tests/sm6/`: 26 of 27 features. `tests/mesh12.cpp` draws with `DispatchMesh` in a render pass and checks pixels: per-vertex colour, per-primitive id, payload, `SV_CullPrimitive` and root constants in the mesh and object stages. |
| `0014-d3d12-report-shader-model-6.8-and-wave-ops.patch` | `CheckFeatureSupport(SHADER_MODEL)` answers any model from 5.1 to 6.9 with the lower of it and 6.8, instead of failing above 6.0. OPTIONS1 reports wave ops with 32 lanes. Verified: `tests/smoke.c` reports shader model 0x68. |
| `0015-d3d12-clock-calibration-and-default-alignment-for-te.patch` | `GetClockCalibration` works (it returned `E_NOTIMPL`, which Unreal Engine's D3D12 renderer treats as fatal) and `GetTimestampFrequency` reports nanoseconds instead of 1; both clocks come from the performance counter. A texture that asks for the 4 KB placement alignment but needs more than 64 KB in Metal gets the default alignment instead of `E_INVALIDARG` (Unreal decides on 4 KB by D3D12's own size estimate). Verified: Ghostrunner (UE4, D3D12) reaches its menus. |

Verify with `tests/smoke.c`, `tests/dlss12.cpp` (`dlss12.exe` and `dlss12.exe hires-mv`), `tests/tiled12.cpp`, `tests/heap12.cpp`, `tests/bary12.cpp`, `tests/atomic12.cpp`, `tests/mesh12.cpp` and `tests/gs12.cpp` (DXMT's geometry shaders with our changes around them), run with `DXMT_ENABLE_NVEXT=1`. Each `.hlsl` next to its `.cpp` is compiled with DXC; see the comment at the top of each `.cpp`. Shader model coverage is in `tests/sm6/` (`run.py`, see `tests/sm6/README.md`). `tests/run-all.sh` builds and runs all of them, DXC and a Wine prefix included, in `../testenv`.
